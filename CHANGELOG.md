# Changelog

## 0.1.0 — initial implementation (unreleased)

- Bounded local TypeScript engine/CLI, strict scenarios, HMAC-signed synthetic events, retries, cancellation and executable HTTP assertions.
- Real PostgreSQL broken/corrected order samples, durable jobs, concurrency/reordering tests, ambiguous acknowledgement loss and owned child-crash recovery.
- Separate file-backed application and read-only adapter example.
- Escaped static HTML/JSON/JUnit reports, keyboard/mobile browser checks and partial-evidence rejection.
- Pinned dependencies, PostgreSQL image and CI actions; setup, security boundaries, maintainer walkthrough and reproducible local evidence.

Tests cover declared synthetic behavior; this is not a provider emulator, certification, live-payment verification or external exactly-once guarantee. No package, deployment or release has been published.
